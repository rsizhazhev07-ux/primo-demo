# Primo — демонстрационное меню

Неофициальная концепция для просмотра и обсуждения.

Сайт: https://rsizhazhev07-ux.github.io/primo-demo/

Реальные заказы не отправляются, платежи не проводятся. Корзина и история тестовых заказов сохраняются только в браузере посетителя. Контакты покупателя вымышленные, изображения блюд временные, созданы AI.

Этот репозиторий содержит готовую статическую сборку сайта. Правила использования шрифта Onest сохранены в assets/Onest-OFL.txt.
